⚙️ Processing Steps Detail
1

Data Collection

Signal strength, latency, bandwidth, packet loss and uptime collected every 5 minutes from all BTS towers, routers, and switches. Customer usage data from CRM.

2

Duplicate Removal

Exact duplicate rows identified using full row comparison. Sensor retry duplicates removed across the network dataset.

3

Missing Value Handling

Null values detected per column. Numeric columns imputed with column mean (signal, bandwidth) or median (latency, packet loss). Customer plan field filled by mode per region.

4

Data Cleaning & Type Casting

Numeric strings cast to float/int. Non-numeric junk values replaced with column means. Categorical fields preserved as-is.

5

Min-Max Normalisation

All numeric features scaled to [0,1]: signal [0–100], latency [0–200ms], bandwidth [0–100%], packet loss [0–20%]. Ensures equal weight in ML algorithms.

6

Feature Engineering

Derived features added including normalised columns (_norm suffix). Network health score = 0.4×signal + 0.3×(1−lat_norm) + 0.2×bw + 0.1×(1−pl_norm).
